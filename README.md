# E-Commerce Customer Behaviour Analysis

## Project Overview
This project focuses on analysing the order history of an e-commerce company using Python and Pandas. The objective is to understand customer purchasing behaviour, identify sales trends, and evaluate factors that influence customer satisfaction and repeat purchases.

The analysis uses order-related data to generate insights that can help businesses improve customer experience and increase customer retention.

## Objectives
The project aims to investigate the following:

1. Calculate the total number of orders and total revenue from completed orders.
2. Identify the highest-performing product categories and cities based on sales.
3. Analyse repeat customers and their purchasing behaviour.
4. Compare the average order value between new and returning customers.
5. Calculate cancellation and return rates.
6. Examine customer ratings across different product categories.
7. Analyse average delivery duration to understand delivery performance.
8. Identify opportunities to improve customer satisfaction and encourage repeat purchases.

## Technologies Used
- **Python** – Programming language used for data analysis.
- **Pandas** – Used for data manipulation, filtering, grouping, and statistical calculations.
- **CSV** – Used as the data source.

## Analysis Performed

### 1. Order Analysis
- Calculated the total number of orders.
- Identified the number of completed orders.
- Calculated total revenue generated from completed orders.

### 2. Category and City Analysis
- Calculated revenue generated by each product category.
- Identified the highest-revenue category.
- Analysed city-wise sales and order distribution.
- Identified the highest-performing city.

### 3. Customer Behaviour Analysis
- Compared average spending between new and returning customers.
- Counted unique returning customers.
- Analysed repeat-purchase behaviour.

### 4. Order Status Analysis
- Calculated the cancellation rate.
- Calculated the return rate.

### 5. Customer Feedback Analysis
- Calculated average customer ratings across product categories.
- Identified the category with the highest average rating.

### 6. Delivery Analysis
- Calculated the average delivery duration for completed orders.

## How to Run the Project

**Step 1:** Clone or download this repository.

**Step 2:** Install Pandas.

```bash
pip install pandas
```

**Step 3:** Make sure `data.csv` and `E-commerce.py` are in the same directory.

**Step 4:** Run the Python file.

```bash
python E-commerce.py
```

The analysis results will be displayed in the terminal.
